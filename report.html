🌍 What and Why of DevOps?

What is DevOps? DevOps is a set of practices that combines software development (Dev) and IT operations (Ops). It aims to shorten the systems development life cycle and provide continuous delivery with high software quality.

Why DevOps? In this project, DevOps methodologies were employed to automate the tedious manual processes of testing, compiling, containerizing, and deploying a Java application. This pipeline ensures that every code change is rigorously validated and seamlessly released without human error.

Tools Used: GitHub (SCM), Maven (Build), JUnit (Testing), Jenkins (CI/CD), Docker (Containerization), Ansible (Deployment).

🚀 Jenkinsfile Explanations: Pipeline Stages

The Jenkins declarative pipeline autonomously guides the project from raw source code to a live container deployment.

  • 1. Checkout Stage

    Pulls the latest source code from the remote main branch on GitHub into the isolated Jenkins workspace.

  • 2. Build Stage

  • 3. Test Stage

  • 4. Package & Docker Build Stage

    The pipeline packages the `.class` files into an executable app.jar. Following this, it utilizes a multi-stage Dockerfile to construct an extremely lightweight container image encapsulating a custom JRE running on Alpine Linux.
